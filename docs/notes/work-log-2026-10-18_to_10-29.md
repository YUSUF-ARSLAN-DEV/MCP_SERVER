## Tue 20 Oct (about 50 commits, roughly 10:00 to 13:30 and later)
From a command-line pipeline to a hosted, multi-user web app, plus report-honesty fixes.

**Report and pipeline fixes (morning)**
- Reconciled the run-over-run delta when a test becomes invalid.
- Generated tests now assert that the *named* option was selected, not just that the value is non-empty.
- The proposer says what to do when a journey's outcome page was never explored.
- Config fails fast on a broken `.env` instead of minutes into a run.
- Ledger test: a defect's whole life (found, persists, fixed, closed) driven through real report builds.
- Journeys can use unlabeled controls and tick or untick checkboxes.
- The AI may no longer write a journey whose outcome is "nothing happens".
- Exploration: only type a search term into a form shaped like a search box; wait for lists that fill in after an earlier choice;
  never record a journey with missing inputs; leave out controls that are not the site's own (skip links, embedded widgets).
- `all` now builds the combined Word report; no parallel-test request when pytest-xdist is missing.
- Report honesty: a run where no test executed gets NO VERDICT (not CONDITIONAL GO); what a run could not observe no longer counts
  against the site; a check that failed before it could see the page is "needs triage", not a defect; the summary document is a
  summary and the detail moved to an appendix.
- After a CAPTCHA answer the page shows what really happened to it.
- Downloads section: changed the number and type of files shown.

**Model providers**
- Pluggable providers so the pipeline is not tied to one server; added Google Gemini (`MODEL_PROVIDER=google`).
- A resend without `chat_template_kwargs` when a strict endpoint (Cerebras, OpenAI) rejects it.
- A run can pick its model (provider, model, address, key) when started.

**Web app**
- Web front end served from `static/`, wired to the API, with a per-run model picker ("SAVING THE NEW UI").
- MLflow-style layout: runs in a sidebar, tabs under each run; each run shows result, duration, model and an "About this run" card;
  compare two runs side by side; every run independent (removed "keep working in this site's folder").
- User accounts: first administrator, sign-in, per-person runs, change password, sign-out, a full-page sign-in / create-account
  screen. Then simplified: removed the administrator role, setup code and Users page; anyone can create their own account.
- Only failed sign-ins count toward the throttle.
- Saved model configurations per person (key encrypted, never shown again) and a Models page; each run names its own model and no
  longer inherits the server's secrets.
- Different people's jobs run at the same time. Run summaries and files are stored in the database instead of on disk.
- Clearer message when an address is refused; an operator option to allow private staging sites.
- `python -m api.reset` empties all data but keeps the tables.

**Docker**
- The web app runs in a container; `docker compose up --build` works from the repo root with no setup; docs for the reset command.

## Sat 24 Oct (about 30 commits, from the morning to 20:12)
**Setup**
- Created the gitignored `credentials.txt` (seed account) and ignored it in git.
- Put the Cerebras key in the gitignored `.env` only, switched the model to Cerebras, answered questions on key storage, Docker
  volumes, the database container and which report file is the real one.
- Deleted `python_artifacts` and all demo runs afterwards (done later, on request, see the end).

**Making the reports actually useful**
- `pagechecks.py`: what the browser itself reports about each page (console and page errors, failed requests, 4xx/5xx), no model
  involved; asks again before calling a failed request a defect; masks keys in URLs.
- `sweep.py`: touches every safe control (links checked by request, safe buttons clicked, fields filled but never submitted).
- Benchmark: a site with seeded faults (broken link, missing image, script error, 404 click, 500 page, blank page, always-failing
  data call, one flaky call) to measure what is found and what is invented.
- Report rules: visitor-facing findings become defects, quality notes stay advisory; what the tool could not establish never counts
  as a defect; browser-found defects persist across runs; a script error about another site's service is a note.
- The front page states how much a verdict rests on (confidence), the three biggest limits of this run, and one short line per
  limitation.

**Stories and MCP**
- A run can be told what the site should do (user stories, use cases, a spec): upload in the web page, API, command line and MCP.
- Wrote 16 user stories for sat.aljazeera.net (`docs/stories/sat-aljazeera-net.md`).
- Thin MCP server in front of the job API (6 tools, tested against the live API).
- Repair failing page tests once by default; a requirements document can yield up to 20, then 24, journeys per run.

**Bugs found and fixed on the way**
- Cerebras returned reasoning only: thinking turned off with `reasoning_effort`.
- The model Test button was blocked by Cloudflare (default Python User-Agent): sent one.
- Rate limits (429/503): every worker waits as long as the provider says.
- jQuery multiselect dropdowns driven properly; the search journey now works; no made-up form submissions; relabelled pickers and
  dropdown rows no longer fail healthy sites.
- Validator accepts an exact text lookup of a name the page really has; delta reconciliation survives a skipped test; stale golden
  fixture regenerated.

**Security**
- Reviewed and hardened the API: security headers, cross-site write refusal, secure cookies, upload limits, and a browser-level
  fence against private addresses. Wrote `docs/SECURITY.md` and `docs/STATUS.md`.

**Result and wrap-up**
- Final run on sat.aljazeera.net (8 pages, 16 stories): GO, 0 defects, 45 of 46 tests passed, 12 journeys verified.
- 1,216 tests passing; everything pushed to `master` (last commit `668fd41`).
- After that, answered deployment questions (Azure options), deleted `python_artifacts` and everything in `runs/` on request.
